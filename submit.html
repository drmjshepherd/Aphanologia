1. Start a new sample

A sample is a single sampling event — one visit to one place, which might contain one specimen or many. Once you've created it, you'll add one or more species observations to it below.

SHADe records the exact physical situation the specimen was found in — its Substrate, Humidity, Acidity, and Disturbance history — as a short code like TsSc-5-6-5. This is genuinely useful research data: it's what lets someone later explore which microhabitats a species actually favours, across every record in the database. Use the tool below to build it step by step — you don't need to memorise the codes.
